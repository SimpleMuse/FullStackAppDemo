# Project Created with Copilot
Copilot was used to scaffold the project, configure front and back end projects and used for debugging initial connection issues. Additionally Copilot was used to optimize the application and introduce caching for the backend api endpoint.

Error catching was added to the frontend for different responses. Copilot was also used to debug an initial issue with the JSON response.

Copilot was used to remove the unneeded demo pages from the project, and to add the FetchProducts page link to the home page and main navigation.
